# Estudio contextual

`EstudioContextual_AA.ipynb` contiene la rama de prototipos promedio K80 separada de
`Experimento_estatico.ipynb`, con sus tablas y gráficos guardados. Reutiliza las redes y recetas del código
común; no tiene bloques GloVe/W2V.

La carpeta queda preparada para incorporar las otras condiciones posteriormente. El notebook actual
corresponde al cierre exploratorio GK97P/GK98P y no acredita todavía la identidad con el AA del estudio
contextual controlado posterior. Las rutas que faltan se indican en `../EstudioEstatico/ExperimentoEstatico/RESULTADOS_PENDIENTES.md`.

El código compartido y `rutas_resultados.json` se encuentran en
`../EstudioEstatico/ExperimentoEstatico/`. El notebook los localiza desde esta carpeta o desde la raíz del proyecto.
