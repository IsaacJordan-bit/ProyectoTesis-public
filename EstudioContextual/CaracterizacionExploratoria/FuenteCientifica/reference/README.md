# Reviewed source metadata

These unmodified records were extracted from the P21 pilot runtime supplied with
the completed classifier-extension review. They identify the P20 A/P/O bank that
the extension reused. Only geometry, cohort and source-protocol metadata are
included; no retrieval predictions or T1/T2/T3 results enter this experiment.

- `bank_identity.json`: reviewed bank ID and historical path.
- `bank_protocol.json`: protocol of the source bank, not a replacement for the
  final adapted-classifier methodology.
- `geometry.json`: original category membership and semantic evaluation edges.
- `full.parquet`, `common.parquet`: original lexical evaluation supports.

The program authenticates the local bank's canonical input receipt and verifies
its algebraic identities. Raw A/P/O arrays must already exist on the user's
computer. These small metadata files do not contain those arrays.
