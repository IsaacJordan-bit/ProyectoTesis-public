# Contextual prototype dataset

The definitive contextual prototypes are stored in an NPZ file
using float64 precision.

Expected local file:

contextual_exp2_embeddings_rawmean100_wordnet_v1.npz

This file is not currently distributed through Git version control.

The dataset is loaded using Codigo/contextual.py and verified
against the documented scientific fingerprints.

The original JSON manifest preserves the provenance and hashes
of the source PKL file.

The membership audit uses the frozen vocabulary and does not
claim to reproduce the unavailable historical WordNet audit.
